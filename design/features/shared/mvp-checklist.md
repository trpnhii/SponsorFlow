# Shared — Checklist nghiệm thu MVP

Dùng cho demo end-to-end với partner.

## Chức năng

- [ ] Tạo tổ chức, dự án; phân ≥ 2 loại tài khoản; quyền server hoạt động
- [ ] Upload `.xlsx`/`.csv` dự trù; map cột; báo lỗi dòng; import editor; sửa SL/đơn giá; tổng tự tính
- [ ] Approve ngân sách v1; sau duyệt chỉnh sửa tạo v2 có diff + lý do
- [ ] Upload chứng từ mẫu; OCR gợi ý; user sửa fields; submit
- [ ] Rule trùng tiềm năng / vượt dự trù hiện cảnh báo; reviewer quyết định; lịch sử lưu
- [ ] Chỉ Approved expenses vào actual & variance; đúng theo từng budget line
- [ ] Tạo hoạt động, đính minh chứng, thêm chỉ số target/actual
- [ ] Xuất PDF báo cáo: nguồn, kỳ, ngày phê duyệt; sponsor chỉ xem published
- [ ] Account sponsor không truy cập dữ liệu/project khác qua URL/API

## Pilot / đo lường

- [ ] ≥ 2 đối tác dùng demo
- [ ] Ghi nhận sơ bộ: độ chính xác OCR theo field, thời gian lập báo cáo, cảnh báo đúng/sai, usability, lỗi phân quyền, chi phí chạy thử

> Mục tiêu định lượng nếu đặt ra chỉ là giả thuyết cần kiểm chứng — chưa phải KPI đã đạt.
